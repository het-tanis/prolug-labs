# Namespaces and virtual links

This lab is part of a larger free workshop and presentation put on by ProLUG.org.
This can be completed on its own, but more context is provided in the study material
found in the ProLUG Discord.

A network namespace is a separate routing and interface table. A veth pair is a
virtual cable between two of them. That is the same building block used by
containers and overlay networks.

Namespaces: `ns1`, `ns2`.
