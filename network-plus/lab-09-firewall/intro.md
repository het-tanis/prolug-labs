# Firewall rules and SSH defaults

This lab is part of a larger free workshop and presentation put on by ProLUG.org.
This can be completed on its own, but more context is provided in the study material
found in the ProLUG Discord.

A firewall is only useful if its rules are testable. You will build an input
chain, block a test service, then harden SSH and inspect the effective config.

The test service runs on `8080`.
